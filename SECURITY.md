# Security policy

Please report vulnerabilities privately through GitHub: open the
**Security** tab of this repository and choose **Report a vulnerability**.
Do not open a public issue for security problems.

Include the platform, the version or commit, a description, and if possible
a proof of concept. We aim to acknowledge reports within 3 working days.

Supported versions: the latest commit on `main`. This app is a
first-generation prototype, not the shipping SingLinkVPN product.

Problems in the protocol itself (handshake, tokens, encryption, server
behaviour) belong to the
[SingLink Beta Protocol repository](https://github.com/SingLinkLabs/singlink-protocol/security).
